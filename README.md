# 팀플 공통 공강 시간 추출기

팀원 3명의 주간 시간표를 입력하고, 월요일부터 금요일까지 1~9교시 중 모두 수업이 없는 시간을 찾아주는 Tkinter 데스크톱 앱입니다.

## 실행 방법

Python 3와 Tkinter가 설치되어 있어야 합니다. 별도의 외부 패키지는 사용하지 않습니다.

Windows PowerShell 또는 명령 프롬프트에서 프로젝트 폴더로 이동한 뒤 실행하세요.

```powershell
python freetime.py
```

`python` 명령을 사용할 수 없는 환경에서는 다음 명령도 시도할 수 있습니다.

```powershell
py freetime.py
```

## 사용 방법

1. **팀원 1, 팀원 2, 팀원 3** 탭에서 시간표를 입력할 사람을 선택합니다.
2. 해당 팀원에게 수업이 있는 요일과 교시 칸을 클릭합니다. 클릭할 때마다 `수업`과 공강이 전환됩니다.
3. 세 사람의 시간표를 모두 입력한 뒤 **공통 공강 찾기**를 누릅니다.
4. 초록색 칸과 결과 영역에서 세 사람 모두 비어 있는 시간을 확인합니다.

## 버튼 안내

- **시연용 예제 입력**: 예제 시간표를 세 팀원에게 입력합니다.
- **전체 초기화**: 세 팀원의 시간표를 모두 비우고 팀원 1 탭으로 돌아갑니다.
- **공통 공강 찾기**: 세 사람의 입력을 비교해 공통 공강과 각 시간대의 수업 인원을 표시합니다.

팀원 탭을 바꾸거나 시간표 칸을 수정하면 결과 표시가 초기화됩니다. 입력한 시간표는 앱 실행 중에만 유지되며 파일에 저장되지 않습니다.

## 시간표 범위

- 요일: 월요일~금요일
- 교시: 1교시(09:00)~9교시(17:00)
- 팀원: 3명
